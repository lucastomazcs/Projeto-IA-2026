ANTES DE COMEÇAR

Ficou alguma dúvida?

Saiba o que você vai encontrar nesta versão.

Já posso usar os valores para definir meu preço?+

Esta versão é um protótipo de frontend. Os preços, margens e anúncios são exemplos fixos para demonstrar a interface; não são recomendações para uma venda real.

Quais produtos aparecem na demonstração?+

A prévia usa anúncios ilustrativos do JBL Tune 510BT e mostra o 520BT como exemplo de modelo diferente. O catálogo de produtos será integrado em outra etapa.

Preciso cadastrar uma conta?+

A ferramenta não tem cadastro próprio. O acesso a esta prévia privada é feito pela conta ChatGPT usada para abrir o site.

A inteligência artificial já está integrada?+

Ainda não. O banco de dados, o modelo de IA e os cálculos definitivos serão integrados depois. Por enquanto, você pode explorar o fluxo visual.
